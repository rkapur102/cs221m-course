At the beginning of last week, we spent some time mapping out what we'll see in the rest of the course. Lecture 5 narrowly defined **mechanistic interpretability** as understanding neural networks through their *causal* mechanisms, and laid out the four areas the rest of the core course takes up in turn: **activation steering** (controlling a model by editing its activations), **causal mediation analysis** (measuring how much of an effect flows through one internal component), **causal abstraction** (stating when a simple algorithm faithfully describes the model’s internal computations), and **counterfactual design** (choosing the right inputs to test a claim). To ground these ideas, the lecture used a transformer that adds two-digit numbers. For example, suppose some hidden vector holds the carry. While a model computes 17 + 25, we can overwrite the vector with its value from a run on 30 + 47, where no carry occurs. If the vector really holds the carry, the model should now answer 32, since the carry from 7 + 5 has vanished. To check whether it does is a simple mechanistic interpretability experiment!

Lecture 6 put this overview into practice by introducing three types of intervention: removing information, understanding the model’s computations, and controlling its behavior. Using OLMo-2 1B, we first measured a profession stereotype with a minimal pair: after “The nurse said that”, the model gave “she” a probability of 0.118 and “he” only 0.057. Switching in “doctor” flipped this pattern. **Iterative nullspace projection (INLP)** then tries to erase that association. It trains a linear probe to detect the stereotype, removes the direction the probe relies on from every activation, and repeats. After two iterations, we saw how a newly trained probe performed at chance level. Notice, though, that this only guarantees that no *linear* probe can find the stereotype; the model is still free to store the same information in a nonlinear form.

A simpler way to remove information is to zero out neurons. However, the notebook’s toy network for outputting the larger of two numbers showed the pitfalls of this approach. Each of its two comparison neurons can block one number from reaching the final layer, which adds whatever arrives. A comparison neuron blocks only when its value is positive, so zeroing both on (1, 3) let both numbers through, and the network returned 1 + 3 = 4. **Interchange interventions** (also called activation patching) avoid choosing a value at all. They run the model on a *source* input, take an activation from that run, and place it into a run on a *base* input. To illustrate this, in the notebook, we first ran the toy network on (7, 2). Then we ran it on (1, 3) with its two copy neurons overwritten by the values they had held for (7, 2). The comparison still picked the second number, but the copy it passed along was now 2, so the network output 2. Overwriting the two comparison neurons instead made it output 1, since the comparison from (7, 2) said the first number was larger. We managed to recover the whole algorithm this way without ever printing an activation value!

Lecture 6 ended with the third type: controlling behavior. Where INLP and patching change activations in ways we specify by hand, **representation fine-tuning (ReFT)** learns the change from examples. It keeps the model’s weights frozen and gradually adjusts the change until the model produces the responses we want. In the notebook, trained on just ten replies written entirely in emojis, it led the model to answer new questions in emojis as well. It's important to understand the distinction here: af all these methods, interchange interventions assume the least about how the model stores information, as they only ever reuse values produced by the model itself.

This week, we'll systematically explore interchange interventions. In Lecture 7, **causal mediation analysis** repeats a single patch at every layer and token position of the following minimal pair: “Eiffel Tower is in the country of” and “Tokyo Tower is in the country of”. We'll see that the result is essentially a map of where information about the landmark sits in the internals and how it travels to the final token! We will then narrow that movement to individual attention heads, using the same method to follow how a model keeps track of the landmark across various sentences. Lecture 8 introduces **causal abstraction** to explain the theory beneath these experiments, which uses interchange interventions to ask when a step-by-step algorithm faithfully describes what the model internally computes. By the end of the week, we will be able to say both where information lives inside a model and whether our understanding of what it does there is accurate.

**What we learned from last week’s lectures**

*Causal methods for interpretability*

* Causal mediation and abstraction theoretically ground mechanistic interpretability.
* Supervised mechanistic interpretability is powerful and effective.
* Benchmarking and evaluations are important.
* Designing counterfactuals is essential for uncovering complex algorithms.

*Interventions for steering activations*

* **Ablations**: structured modifications for removing information in the model.
* **Interchange interventions**: swapping activations between different inputs for identifying causally relevant components.
* **Steering**: interventions optimized to induce behavior in the model.
