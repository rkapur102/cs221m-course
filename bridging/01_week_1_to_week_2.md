We've spent this last week dissecting a simple language model. Given tokens produced so far, a language model calculates probabilities for every possible next token, samples from this distribution, and then repeats. This makes language models **autoregressive**: they only consider previous context (tokens) rather than reasoning about future words as they produce output. In the notebook, we saw this directly from the example of how changing a word *after* “Paris” left the model’s internal representation of “Paris” untouched. Even though it predicts one token at a time, the model processes all the previous tokens in parallel. Each token gets its own vector, and these vectors occupy space side by side in the **residual stream**, which runs through many layers. The vector at the last position after the last layer becomes the prediction.

Each layer has two parts, applied in sequential order: (1) attention and (2) MLP (multi-layer perceptron). **Attention** is how information moves between tokens; in fact, it's the only part of the model that captures word relationships! Every token’s vector is multiplied by a learned matrix to produce a query (“what information am I looking for?”) and by a different learned matrix to produce a key (“what information do I have?”). The dot product of one token’s query with another token’s key determines how strongly the first token **attends** to the second, and each token pulls in information from the tokens it attends to most. In the notebook, we saw this as attention maps with a “head” that also copied patterns from earlier in the sequence.

The **MLP** (multi-layer perceptron) is a basic neural net that runs on each token separately. We multiply the (attention) vector by a weight matrix, apply a nonlinearity, multiply by another matrix, and add the result back into the residual stream. It gets no information from other tokens, so anything it needs from elsewhere in the sentence is brought in by attention first. MLPs make up roughly 70% of the model’s weights, and their activations are sparse, with only a handful of neurons activating strongly for any given token. That combination makes them a natural place for the model to store information. All of these weights, for attention and MLPs alike, were learned from predicting the next token across huge amounts of training data (from conversation and text on the Internet!).

When the course opened, we considered explanations of a model on three levels: behavior, algorithms, and internal mechanisms. This week, we focus on behavior, where many current AI approaches are concentrated. Instead of going inside the model, we go back *outside* to consider, at a high level, whether it solves tasks the right way. A model can score well on a benchmark by using a shortcut or by having memorized test questions during training, but this sort of satisfactory performance does not always signal reasoning or competence in unseen situations. To distinguish, we will build minimal pairs: two inputs where one contains that should move the answer and the other does not. We will also look at *input attribution*, which measures how much each input token contributed to a prediction. By operating “outside” the model internals, this new approach still keeps the model as a black box, but it will set up the questions we will bring back *inside* during the second half of this upcoming week, where we’ll start reading activations directly. We begin with the **logit lens**, move to PCA over activations, and then to supervised **linear probes** trained to recover some property of the input. Once a property can be predicted from a layer, it only follows to attempt to control it, and the *difference-in-means* approach gives us a simple way to try, though the direction that predicts a property best can still fail to move behavior.
